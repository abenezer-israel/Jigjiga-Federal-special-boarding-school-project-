✨ Overview

This project is a modern school website built to provide students, parents, teachers, and visitors with an easy way to explore the school's environment and activities.

The website focuses on clean design, responsive layouts, smooth navigation, and interactive features while keeping the interface simple and accessible.

🚀 Features

- 📱 Fully Responsive — Works across phones, tablets, and desktops
- 🏫 School Overview — Introduction and key areas of the school
- 📚 Academics — Information about academic programs
- 🛏️ Boarding Life — Highlights of the boarding experience
- 👨‍🎓 Student Life — Activities, community, and student experiences
- 🤖 STEM & Innovation — Technology and innovation section
- 📝 Admissions — Admission information and guidance
- 📰 News & Events — School announcements and events
- 🖼️ Gallery — Campus and school-life showcase
- 🏆 Achievements — Highlights and accomplishments
- 🔐 Owner/Admin Portal — Manage website news and announcements
- 💾 Local Storage — Stores demo news data directly in the browser
- 🎨 Modern UI — Clean layout with smooth interactions and animations

🔐 Admin News Management

The project includes a simple Owner/Admin interface that demonstrates how school administrators could manage website announcements.

Administrators can:

- Create news posts
- Publish announcements
- Organize posts by category
- Delete posts
- View published content

«Note: The current admin system is a frontend prototype using browser LocalStorage. It is not intended for production authentication or sensitive information.»

📱 Responsive Design

The website is designed to adapt to different screen sizes:

Desktop → Tablet → Mobile

The goal is to provide a consistent experience regardless of the device being used.
